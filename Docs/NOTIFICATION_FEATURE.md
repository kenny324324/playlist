# 📱 每日推送通知功能說明

## ✨ 功能概述

這個功能會在每天指定的時間發送推送通知，提醒使用者「今日統計資料已準備好」，鼓勵他們每天打開 App，確保排名資料能夠持續記錄。

---

## 🎯 主要功能

### 1. **通知權限管理**
- 自動請求通知權限
- 顯示當前授權狀態
- 可直接跳轉到系統設定修改權限

### 2. **每日提醒設定**
- 開關控制：可自由開啟或關閉每日提醒
- 自訂時間：使用者可以選擇提醒的時間（預設晚上 8:00）
- 自動排程：設定後會自動每天在指定時間發送通知

### 3. **測試功能**
- 提供「發送測試通知」按鈕
- 點擊後 5 秒內收到測試通知
- 方便使用者測試通知是否正常運作

### 4. **自動清除角標**
- App 啟動時自動清除角標數字
- 進入前景時清除角標
- 點擊通知後清除角標

## 📍 使用方式

### 初次設定

1. **開啟 App**
   - 進入「設定」頁面
   - 找到「通知」區塊

2. **授權通知權限**
   - 點擊「通知權限」
   - 在彈出的系統對話框中選擇「允許」

3. **啟用每日提醒**
   - 開啟「每日提醒」開關
   - 點擊「提醒時間」設定你偏好的時間
   - 點擊「保存」

4. **測試通知**
   - 點擊「發送測試通知」
   - 5 秒後會收到測試通知
   - 確認通知正常運作

### 修改設定

#### 變更提醒時間
1. 進入設定 > 通知
2. 點擊「提醒時間」
3. 使用滾輪選擇新的時間
4. 點擊「保存」

#### 暫時關閉提醒
1. 進入設定 > 通知
2. 關閉「每日提醒」開關

#### 重新開啟權限（如果之前拒絕）
1. 進入設定 > 通知
2. 點擊「通知權限」（顯示為「已拒絕」）
3. 會自動跳轉到系統設定
4. 在系統設定中開啟通知權限
5. 返回 App，權限狀態會自動更新

## 🛠️ 技術實作

### 檔案結構

```
Spo.Stats/
├── Services/
│   └── NotificationService.swift      # 通知服務管理器
├── Views/
│   └── SettingsView.swift            # 設定頁面（包含通知設定）
├── AppDelegate.swift                  # 處理通知 delegate
└── Localizable.xcstrings             # 多語言支援
```

### 核心功能

#### NotificationService.swift
- 單例模式管理通知服務
- 請求和檢查授權狀態
- 排程和取消每日通知
- 發送測試通知
- 清除 App 角標

#### SettingsView.swift
- 顯示通知授權狀態
- 每日提醒開關
- 提醒時間選擇器
- 測試通知按鈕

#### AppDelegate.swift
- 設定 UNUserNotificationCenterDelegate
- 處理前景收到通知
- 處理使用者點擊通知
- App 啟動和進入前景時清除角標

### 資料持久化

使用 `@AppStorage` 儲存使用者設定：
- `dailyNotificationEnabled: Bool` - 是否啟用每日提醒（預設 false）
- `dailyNotificationHour: Int` - 提醒小時（預設 20）
- `dailyNotificationMinute: Int` - 提醒分鐘（預設 0）

## 📝 注意事項

### 使用者體驗
1. **非侵入性**：預設關閉，需要使用者主動開啟
2. **可控制**：隨時可以修改時間或關閉
3. **測試友善**：提供測試功能確認通知正常

### 技術限制
1. 通知時間精確到分鐘，但實際發送可能有些許延遲（iOS 系統行為）
2. 如果使用者在系統設定中完全關閉 App 的通知權限，需要手動到系統設定開啟
3. 通知需要 App 安裝在裝置上且未被卸載

### 最佳實踐
1. 建議設定在使用者較常使用 App 的時間（如晚上休閒時間）
2. 測試通知功能可以幫助使用者確認通知設定正確
3. 如果通知未出現，提醒使用者檢查系統通知設定

## 🐛 疑難排解

### Q: 沒有收到通知怎麼辦？

1. 檢查通知權限是否已授權
2. 檢查「每日提醒」開關是否開啟
3. 確認系統設定 > 通知 > Spo.Stats 中的通知已開啟
4. 使用「發送測試通知」功能測試
5. 重新啟動 App

### Q: 測試通知也沒有收到？

1. 檢查手機是否開啟勿擾模式
2. 確認 App 在系統設定中的通知權限狀態
3. 嘗試完全關閉 App 後重新開啟
4. 如果仍然無法收到，可能需要重新安裝 App

### Q: 想要變更通知時間但找不到設定？

1. 進入「設定」標籤
2. 找到「通知」區塊
3. 確保「每日提醒」開關已開啟
4. 點擊「提醒時間」即可修改

### Q: 通知權限顯示「已拒絕」無法修改？

1. 點擊「通知權限」那一行
2. 會自動跳轉到系統設定
3. 在系統設定中開啟「允許通知」
4. 返回 App，狀態會自動更新
