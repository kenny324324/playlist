# App Store 審核說明 - spo.stats

## 📱 測試說明 / Testing Instructions

本應用需要連接 Spotify 帳號才能使用。為了方便審核，我們提供了一個隱藏的展示模式。

This app requires a Spotify account to function. For review purposes, we have provided a hidden demo mode.

---

## 🔑 如何進入展示模式 / How to Access Demo Mode

**中文說明：**
1. 開啟應用程式
2. 在 Home 頁面的登入提示畫面，**快速點擊中央的音樂圖標（灰色音符圖示）5 次**（2 秒內完成）
3. 完成後手機會震動，並自動進入展示模式，無需 Spotify 登入
4. 展示模式中包含完整的模擬數據，可以體驗所有功能

**English Instructions:**
1. Open the app
2. On the Home page login prompt screen, **quickly tap the music icon (gray music note) in the center 5 times** (within 2 seconds)
3. After completion, the device will vibrate and automatically enter demo mode without requiring Spotify login
4. Demo mode contains complete mock data to experience all features

---

## ✅ 展示模式功能 / Demo Mode Features

展示模式提供以下功能的完整體驗：
- 個人音樂統計資料
- 熱門歌曲排行榜
- 藝人和專輯詳情
- 音樂播放器介面
- 數據視覺化圖表

Demo mode provides a complete experience of:
- Personal music statistics
- Top tracks rankings
- Artist and album details
- Music player interface
- Data visualization charts

---

## 📝 備註 / Notes

- 展示模式使用虛構的測試數據，不包含任何真實 Spotify 內容的版權資料
- 正式版本中，展示模式入口完全隱藏，不會影響普通用戶的使用體驗
- 用戶登出後可以重新進入展示模式進行測試

- Demo mode uses fictional test data without any copyrighted Spotify content
- In the production version, the demo mode entrance is completely hidden and will not affect normal user experience
- Users can re-enter demo mode after logging out for testing
