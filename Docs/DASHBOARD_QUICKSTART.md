# 儀表板功能 - 快速入門

## 🚀 如何測試

### 1. 登入 Spotify
在 App 首頁點擊「登入」按鈕，完成 Spotify 授權。

### 2. 查看儀表板
登入後，HomeView 最上方會顯示儀表板區域，包含：

#### 今日聆聽卡片 📊
- 顯示今天的累計播放時間
- 自動從分鐘轉換為小時（當超過 60 分鐘時）
- 顯示最後更新時間

#### 快速捷徑 ⚡
三個快速按鈕：
- ❤️ 收藏歌曲
- 🎵 我的播放清單
- 📊 排行榜

#### 本週熱門歌曲 🎵
- 顯示本週最常聽的前 3 首歌曲
- 包含封面、歌名、藝人
- 點擊「查看全部」可導向完整排行

#### 本週熱門藝人 🎤
- 顯示本週最常聽的前 3 位藝人
- 圓形頭像顯示
- 點擊「查看全部」可導向完整排行

### 3. 刷新資料
點擊右上角的刷新按鈕 🔄，可以重新載入最新的儀表板資料。

## 📱 測試建議

### 測試今日聆聽時間
1. 在 Spotify App 或網頁版播放幾首歌
2. 回到 MyPlaylist App
3. 點擊刷新按鈕
4. 查看「今日聆聽」卡片是否更新

### 測試每週熱門
1. 確保過去一週有在 Spotify 上聽音樂
2. 查看「本週熱門歌曲」和「本週熱門藝人」
3. 應該會顯示你最常聽的內容

### 測試空狀態
如果是新帳號或還沒有足夠的聆聽資料：
- 會顯示友善的空狀態提示
- 引導你開始使用 Spotify

## 🎨 視覺特色

- **Spotify Green**: 儀表板使用 Spotify 標誌性的綠色作為強調色
- **漸層背景**: 今日聆聽卡片使用綠色漸層背景
- **Shimmer 動畫**: 載入時有優雅的閃爍效果
- **圓角卡片**: 一致的 15px 圓角設計

## 🔄 快取機制

儀表板使用智慧快取來提升效能：

- **今日聆聽**: 每次 refresh 時重新計算
- **每週熱門**: 快取 4 小時，避免過度呼叫 API

你可以隨時點擊刷新按鈕來更新資料！

## 🌍 語言支援

儀表板完全支援：
- 繁體中文 (zh-Hant)
- English (en)

系統會根據你的裝置語言自動切換。

## ⚠️ 注意事項

1. 需要登入 Spotify 才能看到儀表板
2. 今日聆聽時間基於 Spotify 的播放記錄，可能有幾分鐘的延遲
3. 每週熱門使用 Spotify 的 "short_term" 資料（約 4 週）

現在你可以一打開 App 就掌握自己的聆聽習慣，探索你的音樂品味！
