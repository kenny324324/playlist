## 🧪 測試項目清單

### ✅ 測試 1：API 響應快取

**目的：** 驗證 API 請求被快取，減少網路請求

**步驟：**
1. 啟動 App 並登入 Spotify
2. 進入 **Top（排行榜）** 頁面
3. 觀察 Console，應該會看到：
   ```
   🌐 從 API 載入 Tracks
   ```
4. 切換到其他頁面（例如 Home）
5. 再次回到 **Top** 頁面
6. **這次應該看到：**
   ```
   ✅ 使用快取的 Tracks 數據
   ```
7. 切換時間範圍（1個月 → 6個月 → 所有時間）
8. 第一次切換每個範圍會看到 `🌐 從 API 載入`
9. 再次切換回相同範圍會看到 `✅ 使用快取`

**預期結果：**
- ✅ 第一次載入需要 1-2 秒
- ✅ 使用快取時幾乎瞬間顯示（< 0.1 秒）
- ✅ 在 5 分鐘內切換不會重新請求 API

---

### ✅ 測試 2：圖片磁碟快取

**目的：** 驗證圖片被儲存到磁碟，App 重啟後無需重新下載

**步驟：**
1. 啟動 App 並登入
2. 瀏覽 Top Tracks，等待所有圖片載入完成
3. **完全關閉 App**（從 iOS 多工畫面向上滑動移除）
4. 重新啟動 App
5. 再次進入 Top Tracks

**預期結果：**
- ✅ 重啟後，圖片**立即顯示**（從磁碟快取載入）
- ✅ 沒有載入動畫或空白佔位符
- ✅ 第一次啟動：圖片逐個載入
- ✅ 第二次啟動：圖片瞬間全部顯示

**對比測試：**
```
優化前：重啟後需要重新下載所有圖片（3-5 秒）
優化後：重啟後立即顯示（< 0.5 秒）
```

---

### ✅ 測試 3：圖片預載機制

**目的：** 驗證圖片在可見前被預載，滾動時無延遲

**步驟：**
1. 進入 Top Tracks 頁面
2. **快速向下滾動**列表
3. 觀察新出現的專輯封面

**預期結果：**
- ✅ 圖片幾乎**瞬間顯示**
- ✅ 沒有明顯的載入延遲
- ✅ 滾動流暢，達到 60 FPS
- ✅ Console 不會顯示大量下載訊息（因為已預載）

**測試技巧：**
- 快速滾動到列表底部
- 觀察是否有「閃爍」或「延遲」
- 優化後應該看起來很流暢

---

### ✅ 測試 4：記憶體使用

**目的：** 驗證記憶體使用在合理範圍內

**步驟：**
1. 在 Xcode 中開啟 **Memory Gauge**
   - 執行 App 後，點擊 Xcode 頂部的記憶體圖表
2. 瀏覽不同頁面（Home, Top, Search）
3. 滾動列表，載入大量圖片
4. 觀察記憶體使用量

**預期結果：**
- ✅ 記憶體使用穩定在 **80-120 MB** 範圍內
- ✅ 沒有持續增長（無記憶體洩漏）
- ✅ 在模擬器上按 **Simulate Memory Warning**
  - 記憶體應該會下降（快取被清理）
  - App 不會崩潰

**測試記憶體警告：**
```
模擬器 → Debug → Simulate Memory Warning
```

### ✅ 測試 5：滾動性能（FPS）

**目的：** 驗證列表滾動達到 60 FPS

**步驟：**
1. 在 Xcode 中開啟 **Debug → View Debugging → Rendering**
2. 勾選 **Color Blended Layers**
3. 在 Top Tracks 頁面快速滾動

**預期結果：**
- ✅ 滾動流暢，無卡頓
- ✅ 手指跟隨即時，無延遲
- ✅ 圖片不會「跳動」或「閃爍」

**進階測試（使用 Instruments）：**
```
Xcode → Product → Profile (Command + I)
選擇 "Time Profiler" 或 "Core Animation"
```

---

### ✅ 測試 6：弱網路環境

**目的：** 驗證在網路不佳時，快取能提供良好體驗

**步驟：**
1. 啟動 App，正常載入數據
2. 在 Mac 上開啟 **Network Link Conditioner**
   - 設定 → 開發者 → Network Link Conditioner
   - 選擇 "3G" 或 "Edge"
3. 在 App 中切換頁面

**預期結果：**
- ✅ 已快取的數據**立即顯示**（不受網路影響）
- ✅ 新數據載入較慢，但 UI 仍然流暢
- ✅ 不會出現「卡死」或「無回應」

---

## 🐛 故障排除

### 問題 1：Console 沒有顯示日誌

**解決方法：**
```
1. 確認 Debug Area 已開啟（Shift + Command + Y）
2. 確認 Console 標籤頁被選中
3. 清除舊日誌（右下角垃圾桶圖示）
```

### 問題 2：快取沒有生效

**檢查步驟：**
```swift
// 在 TopView.swift 的 loadTracks() 中設置斷點
// 確認程式碼執行到快取檢查邏輯
if let cachedTracks = APIResponseCache.shared.getTopTracks(...) {
    // 在這裡設置斷點
}
```

### 問題 3：圖片沒有從磁碟載入

**檢查磁碟快取：**
```bash
# 在終端機執行，查看快取目錄
open ~/Library/Developer/CoreSimulator/Devices/[Device-ID]/data/Containers/Data/Application/[App-ID]/Library/Caches/ImageCache/
```

### 問題 4：記憶體使用過高

**可能原因：**
- 快取限制設定太大
- 記憶體洩漏（但我們已經使用 `weak self`）
- 圖片解壓縮佔用記憶體

**檢查方法：**
```
Xcode → Product → Profile → Leaks
檢查是否有記憶體洩漏
```
