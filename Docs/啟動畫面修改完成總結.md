```swift
private func getAppIcon() -> UIImage? {
    // 嘗試從 app bundle 中讀取實際的 app icon
    if let icons = Bundle.main.object(forInfoDictionaryKey: "CFBundleIcons") as? [String: Any],
       let primaryIcon = icons["CFBundlePrimaryIcon"] as? [String: Any],
       let iconFiles = primaryIcon["CFBundleIconFiles"] as? [String],
       let lastIcon = iconFiles.last {
        return UIImage(named: lastIcon)
    }
    
    // 備用方案：嘗試從 Assets 中讀取
    return UIImage(named: "AppIconImage")
}
```

## 🎬 過渡動畫切換教學

### 快速切換方法

在 `ContentView.swift` 第 59 行，找到這段程式碼：

```swift
private let transitionStyle: LaunchTransitionStyle = .fade  // ← 修改這裡！
```

### 可選的動畫效果

將 `.fade` 替換成以下任一選項：

#### 1. `.fade` - 淡入淡出 ✨ (目前使用)
```swift
private let transitionStyle: LaunchTransitionStyle = .fade
```
- **效果**: 啟動畫面淡出，主畫面淡入
- **特點**: 最優雅、最常見
- **推薦度**: ⭐⭐⭐⭐⭐

---

#### 2. `.scaleUpFade` - 放大淡出 🎯
```swift
private let transitionStyle: LaunchTransitionStyle = .scaleUpFade
```
- **效果**: 啟動畫面放大 1.2 倍同時淡出
- **特點**: 有膨脹感，現代化
- **推薦度**: ⭐⭐⭐⭐

---

#### 3. `.scaleDownFade` - 縮小淡出 🎪
```swift
private let transitionStyle: LaunchTransitionStyle = .scaleDownFade
```
- **效果**: 啟動畫面縮小至 0.8 倍同時淡出
- **特點**: 像是被吸入，聚焦感
- **推薦度**: ⭐⭐⭐⭐

---

#### 4. `.slideUp` - 向上滑動 📱
```swift
private let transitionStyle: LaunchTransitionStyle = .slideUp
```
- **效果**: 啟動畫面向上滑出螢幕
- **特點**: 類似揭開序幕
- **推薦度**: ⭐⭐⭐

---

#### 5. `.slideUpFade` - 向上滑動+淡出 🌊
```swift
private let transitionStyle: LaunchTransitionStyle = .slideUpFade
```
- **效果**: 啟動畫面向上滑出並淡出，主畫面從下方升起並淡入
- **特點**: 流暢自然的雙向轉場
- **推薦度**: ⭐⭐⭐⭐
