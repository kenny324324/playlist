   - 在 Console 搜尋 `[快取命中]`
   - 搜尋 `[API 請求]`
   - 搜尋特定功能日誌

3. **記錄問題**
   - 截圖異常日誌
   - 記錄重現步驟
   - 報告性能問題

### **給開發者：**

1. **善用日誌除錯**
   ```swift
   // 使用全域簡寫
   logger.success("操作成功")
   logger.error("發生錯誤")
   logger.info("資訊提示")
   ```

2. **追蹤性能**
   ```swift
   let startTime = Date()
   // ... 執行操作 ...
   let duration = Date().timeIntervalSince(startTime)
   logger.logPerformanceMetric(action: "操作名稱", duration: duration)
   ```

3. **除錯快取**
   ```swift
   // 觀察快取狀態
   let stats = APIResponseCache.shared.getCacheStats()
   print(stats)
   ```
