## 🧪 **完整測試流程**

### **準備工作**

1. 在 Xcode 開啟專案
2. 選擇模擬器（iPhone 15 Pro）
3. **開啟 Console**：
   ```
   快捷鍵：Shift + Command + Y
   或選單：View → Debug Area → Show Debug Area
   ```

## 🔍 **常見日誌問題**

### **問題 1：Console 沒有輸出**

**原因：** Debug Area 沒有開啟

**解決：**
```
快捷鍵：Shift + Command + Y
或點擊右上角的「Show/Hide Debug Area」按鈕
```

### **問題 2：日誌太多，找不到重要資訊**

**解決：**
```
1. 清除舊日誌（右下角垃圾桶圖示）
2. 使用搜尋功能（Console 右上角搜尋框）
   搜尋：[快取命中]
   搜尋：[API 請求]
   搜尋：[圖片預載]
```

### **問題 3：圖示顯示為方框**

**原因：** 終端機不支援 emoji

**解決：** 這是正常的，實際功能不受影響

### **問題 4：時間不準確**

**原因：** 模擬器時間可能不同步

**解決：**
```
重置模擬器：Device → Erase All Content and Settings
```
