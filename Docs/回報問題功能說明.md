# 回報問題功能說明

## ✅ 已完成實作

### 📧 功能概述

在設定頁面的「關於」區塊加入 **「回報問題」** 按鈕，讓用戶可以輕鬆透過郵件回報問題。

## 🎯 功能特色

### 1. 智能郵件處理

- ✅ **優先使用應用內郵件**（MFMailComposeViewController）
- ✅ **備用方案**：如果應用內郵件不可用，會打開系統郵件 App（mailto）
- ✅ **自動填寫收件人**：`kenny4work324@gmail.com`

### 2. 自動包含系統資訊

當用戶點擊「回報問題」時，郵件會自動包含：

```
請描述您遇到的問題：

[用戶在此輸入問題]

---
系統資訊（請勿刪除）
App Version: 1.0.0 (1)
iOS Version: 17.0
Device: iPhone
---
```

這些資訊可以幫助您更快診斷問題！

### 3. 多語言支援

- 🇹🇼 繁體中文: "回報問題"
- 🇺🇸 英文: "Report an Issue"
- 🇯🇵 日文: "問題を報告"
- 🇰🇷 韓文: "문제 신고"

## 🔍 問題排解

### 問題 1: 點擊按鈕沒反應

**可能原因**：
- 設備未設定郵件帳號
- 郵件應用被禁用

**解決方案**：
- 檢查 Console 日誌
- 確保至少有一個郵件應用（郵件 App、Gmail、Outlook 等）
- 系統會自動嘗試備用方案（mailto）

### 問題 2: 無法在模擬器測試

**原因**：
- iOS 模擬器通常沒有設定郵件帳號
- 這是正常的

**解決方案**：
- 在真實設備上測試
- 或在模擬器的「郵件」App 中設定一個測試帳號

### 問題 3: 想更改收件人郵箱

**修改位置**：

在 `SettingsView.swift` 中：

```swift
// 回報問題
Button(action: {
    HapticManager.shared.light()
    if MailService.shared.canSendMail() {
        showMailComposer = true
    } else {
        MailService.shared.openMailApp(type: .reportIssue)
    }
}) {
    // ...
}
.mailSheet(
    isPresented: $showMailComposer,
    mailType: .reportIssue,
    recipient: "your-new-email@example.com"  // ← 在這裡修改
)
```
