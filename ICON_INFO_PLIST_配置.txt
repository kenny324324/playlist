PlistBuddy 命令（進階用法 - 自動化配置）
================================================================================

將以下命令儲存為 .sh 腳本並執行：

#!/bin/bash
# 自動配置 Info.plist 的 Alternative Icons

PLIST="MyPlaylist/Info.plist"

# 添加主要結構
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons dict" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundlePrimaryIcon dict" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundlePrimaryIcon:CFBundleIconFiles array" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundlePrimaryIcon:CFBundleIconFiles:0 string glass_icon" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundleAlternateIcons dict" "$PLIST" 2>/dev/null

# AppIcon-color2-default
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundleAlternateIcons:AppIcon-color2-default dict" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundleAlternateIcons:AppIcon-color2-default:CFBundleIconFiles array" "$PLIST" 2>/dev/null
/usr/libexec/PlistBuddy -c "Add :CFBundleIcons:CFBundleAlternateIcons:AppIcon-color2-default:CFBundleIconFiles:0 string AlternativeIcons/AppIcon-color2-default" "$PLIST" 2>/dev/null

# AppIcon-color3-default

📝 使用說明
================================================================================

1. 推薦使用「簡化版配置」（9 個 icons）
2. 在 Xcode 中打開 MyPlaylist/Info.plist
3. 右鍵點擊 → Open As → Source Code
4. 將生成的 XML 配置複製貼上
5. 儲存並重新建置專案

注意：
- 確保 AlternativeIcons 資料夾已加入 Xcode 專案
- 使用 "Create folder references" 而不是 "Create groups"
